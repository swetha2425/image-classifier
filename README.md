# MNIST Image Classifier using TensorFlow

A simple deep learning project that classifies handwritten digits (0–9) using the MNIST dataset.

## Features
- TensorFlow/Keras
- MNIST dataset
- Neural Network
- 97.67% Test Accuracy

## Technologies
- Python
- TensorFlow
- NumPy
- Matplotlib
- Jupyter Notebook

## Results
- Training Images: 60,000
- Testing Images: 10,000
- Test Accuracy: 97.67%
